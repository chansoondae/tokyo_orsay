# 오르세 미술관전 「지금을 사는 기쁨」 한국어 작품 목록 · 도슨트

도쿄도 미술관 개관 100주년 기념 **「오르세 미술관 소장 — 지금을 사는 기쁨: 그럼에도 하루하루는 사랑스럽다」**
(東京都美術館 · 2026.11.14 – 2027.3.28) 출품작 112점의 비공식 한국어 브로셔 웹페이지입니다.

전시장에서 휴대폰으로 보는 것을 기준으로 만들었습니다.

- 112점 작품 목록: 7개 섹션(프롤로그 · 1–5장 · 에필로그), 층별(LBF · 1F · 2F) 구성
- 작품별 도슨트 해설과 "이렇게 보세요" 감상 포인트
- 오디오 도슨트: 브라우저 음성 합성, 읽는 문단 강조, 속도 조절
- 층별 안내도: 평면도의 방을 누르면 해당 장으로 이동
- 검색(작가·작품명·번호), ★ 주요작 필터, 실제 크기 비교 그림
- 관람 안내: 회기·시간·휴실일·요금

제작 · 문의: [아트프렌즈 아트버스](https://artfrnd.com/) · info@artfrnd.com

## 실행

```bash
npm install
npm run dev        # 개발 서버 → http://localhost:3000
```

배포용 정적 파일 만들기:

```bash
NEXT_PUBLIC_SITE_URL=https://배포도메인 npm run build   # → out/ 폴더
```

- `out/` 폴더를 그대로 정적 호스팅(Netlify, Vercel, S3, GitHub Pages 등)에 올리면 됩니다.
- `NEXT_PUBLIC_SITE_URL`은 카카오톡 등 링크 공유 미리보기 이미지(og:image)의 절대 주소에 쓰입니다. 지정하지 않으면 미리보기 이미지가 `localhost`로 잡혀 깨집니다.

> **주의**
> - 개발 서버(`npm run dev`)를 켜 둔 채 `npm run build`를 하면 개발 서버의 `.next` 캐시가 덮어써져 오류(500)가 납니다. 빌드 전에 개발 서버를 끄고, 빌드 후 다시 켜세요.
> - 빌드할 때 Google Fonts를 내려받습니다. 네트워크 상태에 따라 `next/font` 오류로 실패할 수 있는데, 대부분 다시 빌드하면 해결됩니다.

## 작품 이미지 넣기

`public/works/`에 **작품 번호로 시작하는 파일명**으로 넣으면 자동으로 연결됩니다.

```
034-des-glaneuses.jpg     ← 권장 형식: 3자리 번호 + 영문 소문자 하이픈
34 Des glaneuses.jpg      ← 이렇게 넣어도 인식됨
107.webp
```

- 지원 형식: `jpg`, `jpeg`, `png`, `webp`, `avif`
- 같은 번호의 파일이 여러 개면 파일명 순서상 첫 번째 파일을 씁니다.
- 이미지가 없는 작품은 "작품 이미지 준비 중"과 이미지 검색 링크가 표시됩니다.
- 개발 서버에서는 새로고침만 하면 바로 반영됩니다. 배포본은 **다시 빌드해야** 반영됩니다.
- 권장 크기는 긴 변 1000px 이상입니다. 현재 이미지는 대부분 500–850px입니다.

현재 이미지가 없는 번호 (32점, 주로 사진·실루엣·공예품):
10, 15, 22, 25, 29–33, 50, 51, 61, 62, 65, 66, 74–81, 83–90, 104

## 내용 수정하기

### 작품 정보: `app/data.ts`
`rows` 배열에서 한 줄이 작품 1점입니다.

```ts
[번호, [작가 한국어, 작가 원어, 생몰년], "한국어 제목", "영어 제목", "일본어 제목", "제작연도", [재료 한국어, 재료 영어], "크기(cm)", 입체여부?, "크기 메모"?],
```

- 크기는 `세로×가로`(평면) 또는 `높이×너비×깊이`(입체)로 씁니다. 크기 비교 그림에 그대로 쓰입니다.
- 섹션은 번호 범위(`chapters`의 `from`–`to`)로 자동 배정됩니다.

### 도슨트 해설: `app/docent-*.ts`
```ts
34: {
  script: ["문단 1", "문단 2", "문단 3"],   // 본문 (해석·맥락 중심)
  look: ["감상 포인트 1", "감상 포인트 2"], // "이렇게 보세요"
},
```

### 주요작(★): `app/notes.ts`의 `HIGHLIGHTS`

### 관람 안내·푸터: `app/Catalogue.tsx`
`<section id="info">`(관람 안내)와 `<footer>` 부분을 수정합니다.

### 층별 안내도: `app/FloorMap.tsx`
- `POS`: 방 번호 배지 위치 (평면도 이미지 기준 % 좌표)
- `AREA`: 방 전체 클릭 영역 (`x`, `y`, `w`, `h` %, 원형 방은 `round: true`)

## 오디오 도슨트

브라우저 내장 음성 합성(Web Speech API)을 씁니다. 별도의 음성 파일은 없습니다.

- 문장 단위로 나눠 차례로 읽습니다. 크롬이 긴 문장을 약 15초 뒤에 끊는 문제를 피하고, 읽는 문단을 강조하기 위해서입니다.
- 화면 글은 그대로 두고, 음성으로 읽을 때만 기호를 다듬습니다 (`WorkSheet.tsx`의 `forSpeech`).
  - 예: 〈〉·따옴표 제거, `cm`→센티미터, `1889–90년`→"1889년부터 90년", 괄호 속 외국어 생략
- 목소리 품질은 기기 내장 음성에 따라 다릅니다. 아이폰의 Yuna, Google 한국어 음성 등을 우선 고릅니다.

## 자료 출처와 주의사항

- **작품 목록:** 전시장 배포 「作品リスト | List of Works」(`list-of-works_orsay.pdf`)를 바탕으로 했습니다.
- **관람 정보:** 공식 포스터를 기준으로 했습니다. 최신 정보는 [도쿄도 미술관](https://www.tobikan.jp)에서 확인하세요.
- **오르세 소장 번호·프랑스어 제목** (`artwork-list.md`):
  - 위키데이터의 오르세 소장 기록과 오르세·RMN 페이지를 기준으로 정리했습니다.
  - ✅ 확인 / 🔶 추정 / ※ 번역 제목(공식 원제 미확인)으로 구분해 표시했습니다.
- **번역 표기:** 작품 제목의 한국어 표기는 번역자 임의 번역입니다.
- **도슨트 해설:** 미술사적으로 널리 알려진 사실 위주로 작성했습니다. 일부 일화는 "전해집니다"로 표시했으니, 공개 전 검토를 권장합니다.
- **성격:** 이 페이지는 전시 주최 측과 관계없는 **비공식** 안내서입니다.
